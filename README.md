# .github

Org-wide defaults for Exploded Views.

GitHub treats a repo named `.github` specially. `profile/README.md` renders as the front page of the [org profile](https://github.com/Exploded-views), and it's where the name gets explained: an exploded view is the diagram that turns a [gitgat](https://gitgat.com/gitgat/) into something you can point at and name.

The rest of the files are default community health files. Any repo in the org that doesn't define its own gets these automatically.

- `CONTRIBUTING.md` covers how to propose changes and the stance on AI-assisted contributions.
- `SUPPORT.md` sets expectations for help on personal projects.
- `SECURITY.md` explains how to report a vulnerability privately.
- `ISSUE_TEMPLATE/` holds the bug report and feature request forms.
- `pull_request_template.md` is the default PR description.

A repo that needs something different should add its own copy rather than changing these, since a change here applies to every repo that hasn't.
