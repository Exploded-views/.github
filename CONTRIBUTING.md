# Contributing

Issues are welcome on any public repository here. If you plan to open a pull request for anything bigger than a typo or small fix, open an issue first so we can agree on the approach before you spend time on it.

Keep pull requests focused on one change, describe what it does and why, and include how you tested it.

Much of the code here is written with AI coding agents, and the commit history says so. Contributions made the same way are fine, as long as you've read and tested what you're submitting.
